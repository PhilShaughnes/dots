dots — declare, track, and wire up files and repos

ABOUT

  Dots is a declarative manifest for your dotfiles and repos. It shows
  you their state, applies what's missing safely, and exposes everything
  as a queryable CLI so your other tools can do their thing.

  The two primitives are symlinks and repos. A dotfile entry creates a
  symlink from anywhere to anywhere. A repo entry clones a git repo to
  a specified location. That's it.

  Write a manifest, put it wherever you want. Use one per machine, one
  shared, or compose them with multiple -f flags.


CONFIG

  [[dotfiles]]
  name = "zshrc"
  src  = "~/dotfiles/.zshrc"   # source in your dotfiles repo
  dest = "~/.zshrc"            # where the symlink is created

  [[repos]]
  name = "nvim"
  url  = "git@github.com:you/nvim.git"
  dest = "~/.config/nvim"

  src and dest accept ~ and absolute paths. Names must be unique across
  all manifests used together. Compose with multiple -f flags:

    dots list  -f base.toml -f work.toml -f projects.toml
    dots apply -f base.toml -f coding.toml

COMMANDS

  dots list  [flags]           show current state of all entries
  dots apply [flags]           create symlinks and clone repos
  dots add   [flags] [dests…]  add an entry to a manifest

ADD FLAGS

  -t repo    write a repo entry (default: dotfile)
  -r root    src root — dest path appended under root
             relative dests give partial structure:
               cd ~/.config
               dots add -r ~/dotfiles alacritty/alacritty.toml
               → src ~/dotfiles/alacritty/alacritty.toml

  Dest paths are arguments or piped via stdin.
  Name defaults to dest basename without leading dot or extension.
  Src defaults to dest if -r is omitted.
  For repo entries, the remote URL is read from the existing repo at dest.
  If no remote is found, a placeholder is written for you to fill in.
  The manifest file is created if it does not exist (-f or DOTS_ROOT required).

FLAGS

  -f file    manifest file, repeatable: -f base.toml -f work.toml
             if omitted, uses dots.toml in current directory
             relative paths resolve against DOTS_ROOT if set
  -t type    filter by type: dotfile, repo
  -s state   filter by state: ok, empty, blocked, src-missing
             supports negation: -s '!ok'
             repeatable:        -s empty -s blocked
  -n name    filter by name (repeatable)
  -o fields  output fields, comma-separated
             available: name, kind, state, src, url, dest
             default:   name, kind, state, dest

ENVIRONMENT

  DOTS_ROOT      directory where manifest files live; resolves relative
                 -f paths and sets the default manifest location
  DOTS_SRCROOT   default src root for dots add (equivalent of -r)

STATES

  ok          correct — symlink points to src, or repo is present
  ok*         just fixed by this apply run
  empty       nothing at dest — safe to apply
  blocked     dest exists but is wrong — needs manual intervention
              (could be a real file, wrong symlink, or non-repo dir)
  src-missing source path does not exist in your dotfiles repo

  apply skips blocked and src-missing entries without error.
  list exits non-zero if any entry is not ok.

STDIN

  Names piped to stdin are used as a name filter for list and apply.
  Paths piped to stdin are used as dest arguments for add.

    dots list -o name | fzf --multi | dots apply
    find ~ -maxdepth 3 -name ".*" -type f | fzf --multi | dots add

EXAMPLES

  Show all entries:
    dots list -f machine.toml

  Show only problems:
    dots list -f machine.toml -s '!ok'

  Apply only repos:
    dots apply -f machine.toml -t repo

  Show blocked entries with their dest paths:
    dots list -f machine.toml -s blocked -o name,dest

  Interactively choose what to apply:
    dots list -f machine.toml -o name | fzf --multi | dots apply -f machine.toml

  Add dotfiles using src root:
    dots add -f machine.toml -r ~/dotfiles ~/.zshrc ~/.tmux.conf

  Add an existing repo:
    dots add -f machine.toml -t repo ~/.config/nvim

  Migrate existing dotfiles into your repo, then apply:
    dots list -f machine.toml -t dotfile -s src-missing -o src,dest \
      | while IFS=$'\t' read -r src dest; do mv "$dest" "$src"; done
    dots apply -f machine.toml

  Back up blocked dotfiles, then apply:
    dots list -f machine.toml -t dotfile -s blocked -o dest \
      | while read -r dest; do mv "$dest" "$dest.bak"; done
    dots apply -f machine.toml

  Check all repos for uncommitted changes:
    dots list -f machine.toml -t repo -o dest \
      | while read -r repo; do git -C "$repo" status --short; done
